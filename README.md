🏙️ Super Trunfo — Comparações Avançadas em C

Programa em C que compara duas cartas de cidades, permitindo ao jogador escolher dois atributos diferentes para determinar o vencedor.
É a versão final e mais avançada do projeto Super Trunfo, integrando tudo o que foi aprendido sobre estruturas de decisão, menus e operadores ternários.

⚙️ Funcionalidades

Exibe informações completas de duas cidades.

Permite escolher dois atributos para comparar.

Usa switch para criar menus dinâmicos.

Garante que o jogador não escolha o mesmo atributo duas vezes.

Aplica regras especiais:

Em todos os atributos, vence o maior valor.

Em densidade demográfica, vence o menor valor.

Soma os valores dos dois atributos para decidir o vencedor final.

Exibe resultados claros e organizados.

🧮 Atributos disponíveis

População

Área

PIB

Pontos turísticos

Densidade demográfica

💡 Densidade demográfica é calculada automaticamente: população ÷ área.

🕹️ Como usar

Compile o código:

gcc super_trunfo_avancado.c -o super_trunfo


Execute:

./super_trunfo


Escolha o primeiro e o segundo atributo para comparar.
